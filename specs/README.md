# SDKWork App Topology Contracts

`component.spec.json` declares the reusable application lifecycle/topology
framework boundary. `topology.schema.v5.json` is a synchronized distribution
copy of the canonical schema in
`../sdkwork-specs/schemas/sdkwork.app.topology.schema.v5.json`; tests fail when
the two diverge. Version 1 and version 2 schemas remain migration readers only.
